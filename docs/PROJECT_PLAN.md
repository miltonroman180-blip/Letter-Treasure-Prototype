# Project Plan

## Goal

在 2 个迭代内交付一个可演示的 Letter Treasure Prototype（Web）。

## Iteration 1（基础玩法）

### Objectives

1. 构建可点击的 5x5 字母网格。
2. 支持“选词提交”与合法性校验（本地词典）。
3. 实现基础计分规则并展示回合分数。

### Deliverables

- 网格渲染组件（支持重置）
- 选词流程（鼠标拖拽或点选）
- 计分模块（纯函数）
- 最小测试集（至少覆盖计分与校验）

### Exit Criteria

- 用户可在页面完整进行一回合并看到最终分数。
- 单元测试通过。

## Iteration 2（可玩性增强）

### Objectives

1. 增加回合计时与结束状态。
2. 增加难度参数（网格尺寸、奖励字母）。
3. 完成一次内部试玩并记录反馈。

### Deliverables

- 计时器与结束弹层
- 难度配置面板
- 试玩反馈记录文档

### Exit Criteria

- 不同难度下都能完成流程。
- 至少记录 5 条可执行反馈并形成下一步 backlog。

## Backlog（按优先级）

1. 词典数据源选择与体积控制
2. 网格随机生成策略（避免无词可选）
3. 分数平衡（长词奖励与稀有字母奖励）
4. UI 反馈（路径高亮、错误提示）
5. 数据埋点（回合时长、提交次数、有效词比例）

## Working Agreements

- 每次提交必须包含：变更说明 + 可验证结果。
- 新增逻辑优先写成纯函数，方便测试。
- 出现不确定性时先提交最小可验证版本（thin slice）。
